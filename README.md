# cerrajeroscanillejas.com

Tema hijo de WordPress **Cerrajeros Canillejas** (bloques / Full Site Editing) basado en
**Prime FSE**.

| Ruta | Contenido |
| --- | --- |
| `cerrajeros-canillejas/` | El tema hijo instalable (`Template: prime-fse`). |
| `prime-fse.1.1.2.zip` | Tema padre Prime FSE 1.1.2, sin modificar. |
| `brand/` | Logotipo original facilitado (fuente de los archivos del tema). |

## Instalación rápida

1. Instala el tema padre **Prime FSE** (desde el directorio de WordPress o subiendo `prime-fse.1.1.2.zip`).
2. Comprime la carpeta `cerrajeros-canillejas` en un `.zip`:
   ```sh
   zip -r cerrajeros-canillejas.zip cerrajeros-canillejas
   ```
   y súbelo en **Apariencia → Temas → Añadir nuevo → Subir tema**.
3. Activa **Cerrajeros Canillejas**.
4. En **Ajustes → Lectura**, elige una página estática de inicio («Inicio») y una página de entradas («Blog»).

Requisitos: WordPress 6.6 o superior (theme.json versión 3) y PHP 7.4 o superior.
No necesita plugins.
